# Third-party software in WiiDrop

`wiidrop.wuhb` contains the following libraries (statically linked). Each stays under its own license;
the full license texts are in each project's source distribution, linked below.

## Included in this repository (`source/`)

| Component | Use | License |
|---|---|---|
| [LZMA SDK](https://www.7-zip.org/sdk.html) C decoder (7-Zip 26.06), `source/lzma/` | .7z extraction, RVZ/WIA LZMA | Public domain |
| [Zstandard](https://github.com/facebook/zstd) 1.5.7 decompressor, `source/zstd/` | RVZ Zstandard | BSD-3-Clause (dual-licensed with GPL-2.0) |

WiiDrop itself is GPL-3.0-or-later. Every library above can be combined with it: the permissive ones (zlib, MIT,
BSD, curl, libpng, IJG, bzip2, public domain) and Apache-2.0 directly; libmpg123's LGPL-2.1 too; Zstandard is used
under its BSD-3-Clause option and FreeType under its GPL-2.0-or-later option (FreeType is dual-licensed FTL / GPL).

Portions of this software are copyright © The FreeType Project (https://freetype.org). All rights reserved.

**About the LGPL (libmpg123):** WiiDrop's complete source code and build files are published with each release,
so anyone can rebuild `wiidrop.wuhb` against a modified libmpg123, as the LGPL-2.1 requires.

## Not included

- The font is the Wii U's own system font, read from the console's memory at runtime; it isn't distributed with
  WiiDrop.
- Box art and the title list come from [GameTDB](https://www.gametdb.com) and are downloaded by the console at
  runtime.
- The background music is original and generated by WiiDrop's own code (`source/bgm.c`).
